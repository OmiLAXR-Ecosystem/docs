# AGENTS.md

This file provides guidance to coding agents when working with code in this repository.

Documentation site of the OmiLAXR ecosystem (<https://docs.omilaxr.dev>), built with Astro 7 and Starlight. Commands and deployment are in `README.md` (`make help`).

## How the site is put together

- `packages.json` lists the package repos (and optionally a `ref`, default `main`). Its order is the sidebar order.
- `scripts/packages.mjs` clones them into `.packages/` (or, with `--local <dir>`, uses the checkouts in a workspace folder) and runs `export-docs` from OmiLAXR.MCP (`dotnet run`). The exporter writes `src/content/docs/<slug>/` per package and `src/generated/packages.json`, the manifest with each package's sidebar. `astro.config.mjs` and `src/components/PackageCards.astro` read that manifest.
- Slugs: `core` for `com.rwth.unity.omilaxr`, otherwise the name after `com.rwth.unity.omilaxr.` (`xapi`, `unityxr`, …).
- What a generated page contains is decided in OmiLAXR.MCP (`src/OmiLAXR.MCP/Docs/DocsExporter.cs`), not here. Change the exporter there and rebuild.

## Rules

- Everything in `src/content/docs/` is generated and gitignored, except `index.mdx` and `start/`. A new hand-written page or folder there needs a `!` exception in `.gitignore`, and its name must not clash with a package slug.
- Package content (guides, component text) belongs in the package's `Documentation~/`, not here. This repo only holds pages that span all packages.
- Generated pages set `editUrl: false`. Pages copied from `Documentation~/` link "Edit page" to the package repo.
- Starlight ≥ 0.39: an autogenerated sidebar group is `{ label, items: [{ autogenerate: { directory } }] }`; `autogenerate` next to `label` is rejected.
- `scripts/new-page.mjs` and the `check`/`new-page`/`new-component`/`publish` targets are called by the `Makefile` in each package (`make docs-*`). Keep their arguments stable.
